# SwiftShip Tracker

Salesforce-Based Parcel Delivery Management System

## About

SwiftShip Tracker is a Salesforce-based project for managing parcel booking, tracking, delivery updates, and customer communication.

## Technologies Used

* Salesforce
* Agentforce AI
* Flow Builder
* Prompt Builder
* Custom Objects

## Features

* Parcel Booking
* Parcel Tracking
* Delivery Updates
* Customer Support
* Automated Parcel Information
